# مغامرات صفية والوليد — مشروع بناء APK سحابي

هذا المشروع يغلّف ملف اللعبة HTML داخل تطبيق Android باستخدام WebView. ملف اللعبة مضمن محليًا في `app/src/main/assets/index.html`، ولذلك لا يحتاج تشغيل اللعبة إلى استضافة ويب أو اتصال إنترنت بعد تثبيت التطبيق، طالما أن موارد اللعبة مضمنة في ملف HTML.

## بناء APK عبر GitHub Actions

1. نزّل الملف المضغوط وفك ضغطه على الكمبيوتر.
2. أنشئ مستودعًا جديدًا على GitHub باسم `Maghamarat-Safiya-Waleed`.
3. ارفع **محتويات المجلد** إلى المستودع (لا ترفع ملف ZIP وحده). تأكد أن `app` و`.github` و`build.gradle` و`settings.gradle` تظهر في جذر المستودع.
4. افتح تبويب **Actions** في المستودع ووافق على تفعيل Actions إذا طُلب ذلك.
5. اختر سير العمل **Build Android APK** ثم اضغط **Run workflow**، أو انتظر تشغيله بعد رفع الملفات إلى فرع `main`.
6. انتظر حتى تظهر علامة نجاح خضراء.
7. افتح عملية البناء الناجحة، وانزل إلى قسم **Artifacts**، ثم نزّل `Maghamarat-Safiya-Waleed-APK.zip`.
8. فك ضغط ملف Artifacts؛ ستجد `app-debug.apk`. انقله إلى هاتف Android وافتحه للتثبيت. قد تحتاج السماح بالتثبيت من هذا المصدر في إعدادات الهاتف.

## ملاحظات

- ملف `app-debug.apk` مخصص للتجربة والتثبيت المباشر، وهو ليس نسخة Release موقعة للنشر على Google Play.
- لا تحتاج إلى `gradlew` أو `gradle-wrapper.jar` لأن سير العمل يجهّز Gradle في بيئة البناء السحابية.
- اسم الحزمة الحالي: `com.safiya.waleed.game`.
- إذا عدّلت اللعبة لاحقًا، استبدل `app/src/main/assets/index.html` بالنسخة الجديدة ثم ارفع التغيير إلى GitHub وأعد البناء.

## التحديثات المضافة
- إضافة أيقونة اللعبة المعتمدة إلى موارد أندرويد بأحجام متعددة.
- اسم التطبيق أسفل الأيقونة: **مغامرات صفية والوليد**.
- تحسين موسيقى الخلفية الحماسية أثناء اللعب، مع زر تشغيل/إيقاف.
- إضافة نافذة **حول اللعبة** وتتضمن وصف اللعبة وخيار التحكم في صوت الخلفية وعبارة: **تنفيذ اللعبة بالذكاء الاصطناعي — عبدالعزيز سعيدان**.
